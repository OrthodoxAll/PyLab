# Виджет последних операций для личного кабинета клиента банка

Контекст задачи
IT-отдел крупного банка делает новую фичу – виджет на странице личного кабинета, который показывает несколько последних успешных банковских операций клиента. Бэкенд будет готовить данные для отображения в этом виджете.

## Установка и использование

1. Клонируйте репозиторий:
```
git clone git@github.com:OrthodoxAll/PyLab.git
```
2. Установите зависимости:
```
poetry install
```
## Использование:

Функция принимает номер карт и аккаунта и шифрует его
[masks.py](src/masks.py)


Функции для маскировки карт и счетов, преобразования дат
[widget.py](src/widget.py)

Функции для филтрации и сортировки словарей
[processing.py](src/processing.py)
