# Виджет последних операций для личного кабинета клиента банка

Контекст задачи
IT-отдел крупного банка делает новую фичу – виджет на странице личного кабинета, который показывает несколько последних успешных банковских операций клиента. Бэкенд будет готовить данные для отображения в этом виджете.

## Установка и использование

1. Клонируйте репозиторий:
```
git clone git@github.com:OrthodoxAll/PyLab.git
```
2. Установите зависимости:
```
poetry install
```

## Тестирование

### Функции и сценарии:

#### 1. Маскировка номеров карт и счетов
- Проверка правильности маскировки номеров карт и счетов по формату.
- Параметризация тестов для различных корректных и некорректных входных данных.
- Тесты на обработку ошибок (ValueError) при невалидных номерах.

#### 2. mask_account_card
- Тестирование корректной обработки строк с картами и счетами разных типов.
- Проверка универсальности функции с помощью набора разных входных данных.
- Тесты на устойчивость к ошибкам и некорректным строкам (например, отсутствие номера, неверная длина и формат).

#### 3. get_date
- Проверка преобразования строки даты из ISO-формата в формат "ДД.ММ.ГГГГ".
- Тестирование функции на граничные, стандартные и нестандартные случаи.
- Проверка обработки некорректных и пустых значений (возврат сообщения об ошибке).

#### 4. filter_by_state
- Проверка фильтрации по различным значениям состояния (state) через параметризацию.
- Проверка работы с пустым списком.
- Проверка фильтрации по умолчанию ("EXECUTED").
- Тестирование отсутствия нужных статусов в списке.

#### 5. sort_by_date
- Проверка сортировки по дате в порядке убывания и возрастания.
- Тесты с одинаковыми значениями даты.
- Проверка обработки некорректных или отсутствующих дат.
- Проверка работы с пустым списком.

## Структура тестов:
- Используется параметризация для сокращения дублирования кода и расширения охвата тестируемых сценариев.
- Для повторяющихся данных применяются фикстуры.
- Во всех случаях проверяется выброс ожидаемых исключений при ошибочном вводе.

## Как запускать тесты
Выполните команду pytest в корневой директории проекта.
